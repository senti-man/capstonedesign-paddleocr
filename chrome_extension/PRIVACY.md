# 개인정보 처리방침 (Privacy Policy)

이 확장 프로그램("Gmail 개인정보 마스킹 도우미")은 다음과 같이 동작합니다.

## 수집하는 정보

- 이 확장 프로그램은 사용자의 개인정보를 외부 서버로 전송하거나 수집하지 않습니다.
- Gmail에서 첨부하거나 다운로드하는 파일, 작성 중인 이메일 본문, 받은 메일의 피싱 의심도 검사 대상 텍스트는 오직 **사용자 본인의 컴퓨터에서 실행되는 로컬 서버(`http://127.0.0.1:5000`)**로만 전송되어 처리됩니다.
- OCR(문자 인식)과 개인정보·피싱 탐지 로직(PaddleOCR, 정규식 기반 규칙)은 전부 로컬에서 실행되며, 인터넷의 외부 API로 파일이나 텍스트를 전송하지 않습니다.

## 저장하는 정보

- 확장 프로그램 사용 통계(감지·마스킹·전송 차단 횟수)는 `chrome.storage.local`을 통해 **사용자의 브라우저 안에만** 저장됩니다. 개발자를 포함한 그 누구도 이 통계에 접근할 수 없습니다.
- 팝업의 "통계 초기화" 버튼으로 언제든 삭제할 수 있습니다.

## 권한 사용 목적

| 권한 | 목적 |
|---|---|
| `activeTab` / `scripting` | Gmail 탭에서 첨부파일·본문·수신 메일을 감지하고 마스킹/경고 UI를 표시하기 위함 |
| `storage` | 위 통계를 로컬에 저장하기 위함 |
| `host_permissions: mail.google.com` | Gmail 페이지에서만 동작하도록 제한하기 위함 |

## 로컬 백엔드 서버

이 확장 프로그램은 `masking_module/server.py`(Flask, PaddleOCR 기반)가 사용자 PC에서 실행 중이어야 동작합니다. 이 서버는 사용자 본인만 접근 가능한 `127.0.0.1`(로컬호스트)에서만 수신 대기하며, 외부 네트워크에 노출되지 않습니다.

## 문의

이 프로젝트는 학교 캡스톤디자인 과제로 제작되었으며, 상업적 서비스가 아닙니다.
